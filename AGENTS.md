# Project guidance

Before support, issue triage, release planning, or implementation work, read
`docs/private/AGENTS.md` and follow its issue-tracker maintenance instructions.
Also read that file before working anywhere under `docs/private/`.

The private directory is deliberately excluded from Git. Do not force-add or
publish its contents. This pointer does not authorize reading unrelated private
captures, changing issue status on GitHub, or committing/pushing changes.
