# rtl_433-Assisted Learning

The old **Learn from rtl_433 output** JSON-paste setup has been replaced by
**Enter a Learning ID**, which supports legacy and extended remotes.

Use [Using rtl_433 for learning](Using_rtl_433_for_learning.md) for receiver and
software requirements, helper download/inspection, remote button instructions, and
troubleshooting. rtl_433 and the standalone helper run outside Home Assistant.

Already have an ID? See [Using Learning IDs](add_fireplace_profile.md#Using_learning_ids)
to import it and choose your fireplace features and controller.

This page remains available so older documentation links still lead to the
current workflow. Older integration releases may still offer the original paste
flow; update to a release containing Learning ID support to use these instructions.
